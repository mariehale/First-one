# SOP 4: Session Day Workflow

Same steps, every visit, whether it's visit 1 of 6 or visit 6 of 6.

1. **Review the plan.** Pull up the Strategy Plan phase for today from the Initial State Report (or the last Progress Report if this isn't visit 1).
2. **Photos first.** If this space hasn't been shot yet this job, do the full `sop/02-photo-capture-protocol.md` checklist before touching anything.
3. **Empty the space** completely onto a clear surface (bed, floor, table).
4. **Sort into 4 physical piles**, labeled bins/bags: **Keep / Sell / Donate / Toss.**
   - Use the coaching scripts in `sop/10-coaching-language-guide.md` if the client is present and struggling with a decision — no pressure, permission-based questions only.
5. **Mid-session marketplace pass (optional, if time allows).** Photograph the Sell pile now rather than at the very end — see `sop/07-marketplace-pipeline.md`.
6. **Clean the empty space** (wipe shelves/drawers, vacuum if needed).
7. **Return Keep items** using the zone/label plan from the Strategy Plan — every category gets one home, and it gets labeled.
8. **Load the Donate pile into the car same day.** Never leave it behind — that's the #1 way "donate" piles quietly become clutter again.
9. **After-photos**, mirroring the exact Before angles (same doorway spot, same wall order).
10. **2-minute walkthrough with the client** before you leave: show them the new system, tell them one thing to maintain it, ask if anything's off.
11. **Log the visit immediately** (in the car, before you drive off) in `tracker/sessions.csv`: date, spaces completed, hours, Sell/Donate pile size.
12. That evening or next morning: generate the Progress Report (`sop/05-progress-report.md`) and the Workbook (`sop/06-coaching-workbook.md`) and send both.

## Honey's pacing (built in, not optional)
- Set a timer for 45–50 minutes of work, then a 5–10 minute break — every session, no exceptions, even mid-room.
- Job bag always has: noise-reducing earbuds/headphones, a water bottle, gloves, and the printed one-page checklists from SOPs 2 and this one.
- If a space is unexpectedly overwhelming (dust, smell, bugs, hoarding-level volume), it's okay to stop and reschedule with different prep (masks, more bins, a shorter session). That's a judgment call, not a failure.
