# SOP 2: Photo Capture Protocol (Honey's job)

This is the most important checklist in the whole business. Every report, estimate, and workbook depends on these photos being complete and consistent. Follow the same order every single time — same order means nothing gets missed and every job's photos compare the same way.

## The rule
**No photos, no touching.** Before a single item moves, the space gets fully photographed.

## Per-space checklist (check each box before moving to the next space)
- [ ] One wide shot from the doorway
- [ ] One shot of each wall, standing in the same spot each time
- [ ] Every cabinet/drawer/closet — open it, photograph inside
- [ ] Floor-level shot (get low — shows what's stacked on the floor)
- [ ] High storage / shelves near the ceiling
- [ ] Anything broken, damaged, or already labeled "donate" by the client

## File naming (do this before you leave the room, not later)
`LastName_YYYY-MM-DD_RoomName_Before_01.jpg` (then `_02`, `_03`...)

Example: `Nguyen_2026-09-25_Pantry_Before_01.jpg`

## Where it goes
Upload to Google Drive immediately, same day:
`/Clients/<ClientLastName>/<Date>/Before/`

(After photos at the end of a visit go in `/After/` using the exact same angles — stand in the same doorway spot, same wall order. That's what makes the before/after comparison in the progress report actually work.)

## Marketplace items get extra photos
Anything landing in the "Sell" pile needs its own separate photo set — see `sop/07-marketplace-pipeline.md` for that checklist (more angles, close-ups on flaws, something for scale).

## Honey's one-page version
Print this and keep it in the job bag:
1. Walk in. Don't touch anything yet.
2. Doorway shot.
3. Each wall, left to right.
4. Open every door/drawer. Photo inside.
5. Floor shot. Ceiling/high shelf shot.
6. Check the list. All boxes checked? Then we start.
