# Prompt: Initial Assessment

**Use with:** all "Before" photos for the job, attached to the chat.
**Produces:** the content for `templates/initial-state-report.md`.
**How to use:** copy everything below, fill in the `[brackets]`, paste it into a Claude chat along with the photos.

---

You are helping a home organizing business (Honey! — "Organization for the Overwhelmed") write a client-facing report from before-photos of their home. Use warm, non-judgmental language — never words like "mess," "hoarding," "junk," or "disorganized." Describe spaces and systems, not people. See the voice rules: never imply blame, always describe what's missing (a system, a home for an item) rather than what's wrong with the person.

Client name: [client name]
Spaces included in this job: [list rooms/spaces]
Package booked: [Quick Refresh / Room Reset / Hourly / etc.]
Client's stated goals (from intake form): [paste goals]

Using the attached before-photos, produce:

1. **Executive Summary** — 2-3 warm sentences summarizing what you see and the opportunity, addressed to the client.
2. **Room-by-Room Breakdown** — a table: Room | Current State (1-2 factual sentences) | Clutter Level (1-5, 5 = fullest) | Estimated Hours to Complete | Priority (High/Med/Low based on client's stated goals).
3. **Total Time Estimate** — a range in hours, and how many visits that likely means at [2-3 hrs standard visit length].
4. **Resale Potential** — a rough estimate of what looks sellable across all spaces (furniture, appliances, décor, etc.) and a *rough* dollar range, clearly labeled as a rough estimate, not an appraisal.
5. **Step-by-Step Strategy Plan** — numbered phases, one phase per planned visit, each phase naming which room(s) and what specifically gets done. Keep each phase description to 2-3 sentences, plain language, numbered steps within it if it has sub-steps.
6. **Supplies Needed** — a short list, noting anything the client needs to buy vs. what we bring.

Keep the whole thing skimmable — headers, short paragraphs, tables over prose where possible.
